# Seeds Dataset Classification and Clustering

Проект посвящён анализу датасета **Seeds** и решению двух задач машинного обучения:

1. **многоклассовая классификация** семян пшеницы;
2. **кластеризация** объектов без использования целевого признака.

В рамках работы был выполнен полный пайплайн: первичный анализ данных, стандартизация признаков, понижение размерности с помощью PCA, обучение нескольких моделей, подбор гиперпараметров через GridSearchCV и сравнение качества на тестовой выборке.

---

## О датасете

Датасет Seeds содержит 7 числовых признаков, описывающих геометрические характеристики зерна пшеницы, и целевой класс:

- `feature_1`
- `feature_2`
- `feature_3`
- `feature_4`
- `feature_5`
- `feature_6`
- `feature_7`
- `target`

Классы:
- `1`
- `2`
- `3`

---

## Что было сделано

В проекте выполнены следующие этапы:

- загрузка и первичный анализ данных;
- проверка размерности, типов данных и статистических характеристик;
- стандартизация признаков с помощью `StandardScaler`;
- визуализация данных после понижения размерности с помощью `PCA`;
- обучение и сравнение нескольких моделей классификации;
- подбор гиперпараметров через `GridSearchCV`;
- оценка качества по метрикам `accuracy` и `f1_macro`;
- решение задачи кластеризации с помощью `KMeans`;
- визуализация кластеров в двумерном пространстве.

---

## Использованные модели

Для задачи классификации были рассмотрены:

- `KNeighborsClassifier`
- `SVC`
- `DecisionTreeClassifier`
- `RandomForestClassifier`
- `GradientBoostingClassifier`
- `XGBClassifier`

Для задачи кластеризации использовался:

- `KMeans`

---

## Результаты классификации

После подбора параметров и проверки на тестовой выборке были получены следующие результаты:

- **KNN**: `accuracy = 0.8571`, `f1_macro = 0.8499`
- **SVC**: `accuracy = 0.9048`, `f1_macro = 0.9007`
- **Decision Tree**: `accuracy = 0.9762`, `f1_macro = 0.9762`
- **Random Forest**: `accuracy = 0.8571`, `f1_macro = 0.8514`
- **Gradient Boosting**: `accuracy = 0.8810`, `f1_macro = 0.8731`
- **XGBoost**: `accuracy = 0.9048`, `f1_macro = 0.9000`

### Лучший результат

Наилучшее качество показала модель:

- **Decision Tree Classifier**

---

## Кластеризация

Дополнительно была решена задача кластеризации без использования целевой переменной.

Для этого были выполнены:

- удаление целевого признака `target`;
- стандартизация признаков;
- подбор числа кластеров методом «локтя»;
- обучение модели `KMeans`;
- визуализация результатов после `PCA`.

Оптимальным числом кластеров было выбрано **3**, что соответствует количеству классов в исходном датасете.
